# Reverse Animation

## <mark style="background-color:$success;">What It Does</mark>

Reverse Animation reverses selected Animation Sequence data while keeping the existing playback Rate Scale unchanged.

## Options

The reverse operation supports <mark style="color:blue;">**Bone Tracks, Curves, Notifies, Sync Markers, and Root Motion**</mark>. Each element can be <mark style="color:$success;">**reversed independently**</mark>, so you can <mark style="color:$success;">**reverse only the specific data**</mark> you need <mark style="color:$success;">**without reversing the entire animation**</mark>.

* <mark style="color:cyan;">**Bone Tracks**</mark> — reverses position, rotation, and scale keys of animation.
* <mark style="color:cyan;">**Curves**</mark> — reverses animation curve keys.
* <mark style="color:cyan;">**Notifies**</mark> — reverses animation notify timing.
* <mark style="color:cyan;">**Sync Markers**</mark> — reverses authored sync-marker timing.
* <mark style="color:cyan;">**Root Motion**</mark> — includes Root Motion data in the reverse operation.

## Workflow

1. Enable the data types you want to reverse.
2. Click **Reverse Animation**.
3. Review the Analysis Log.

At least one reverse option must be selected.

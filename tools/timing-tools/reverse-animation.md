# Reverse Animation

## What It Does

Reverse Animation reverses selected Animation Sequence data while keeping the existing playback Rate Scale unchanged.

## Options

* **Bone Tracks** — reverses position, rotation, and scale keys.
* **Curves** — reverses animation curve keys.
* **Notifies** — reverses animation notify timing.
* **Sync Markers** — reverses authored sync-marker timing.
* **Root Motion** — includes Root Motion data in the reverse operation.

## Workflow

1. Enable the data types you want to reverse.
2. Click **Reverse Animation**.
3. Review the Analysis Log.

At least one reverse option must be selected.

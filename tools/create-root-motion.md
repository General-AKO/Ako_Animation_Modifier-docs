# Create Root Motion

## What It Does

Create Root Motion transfers Pelvis motion to the Root so the resulting Animation Sequence contains Root Motion.

## Inputs

Choose:

- Root Bone
- Pelvis Bone
- Translation axes
- Transfer method

The selected Pelvis must be below the selected Root in the Skeleton hierarchy.

## Workflow

Use the staged Root/Pelvis workflow to analyze and prepare the motion, then apply the Root Motion transfer once the required selections and checks are complete.

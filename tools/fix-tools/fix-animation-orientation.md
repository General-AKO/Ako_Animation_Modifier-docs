# Fix Animation Orientation

## What It Does

Fix Animation Orientation rotates the Root Motion translation path so the animation travels in the required direction.

Use it when the animation moves correctly but its travel direction does not match your intended setup.

## Workflow

1. Choose the **Root Local Reference Axis**: Local X, Local Y, or Local Z.
2. Click **Analyze Root Motion**.
3. Review the **Direction Preview**.
4. Set the direction change from **-180° to +180°**.
5. Use a quick alignment button when helpful:
   - Align to +X / -X
   - Align to +Y / -Y
   - Reverse Direction
6. Choose the **Alignment Space**: World or Local.
7. Click **Apply New Direction**.

## Preview

The analysis reports the Original Direction, New Direction, and Offset so you can verify the change before applying it.

# Support

<mark style="color:$danger;">**If you encounter any issues, we’d really appreciate the opportunity to discuss them with you first and help find a solution. Thank you!**</mark>\
\
**Discord link :&#x20;**<mark style="background-color:$success;">**https://discord.gg/UEdMYzEe48**</mark>

When reporting a problem, provide:

* **Unreal Engine version**
* **the specific tools you use when the bug is happening**
* **Ako Animation Modifier version**
* **Exact error or result message IF YOU CAN**
* **IS YOU PROJECT HAVE C++ FILE ??**
* **What you selected or configured before the problem occurred**
* **please post your post in&#x20;**<mark style="color:$success;">**help**</mark>**&#x20;section Discord**
* **I might be a little late in replying, but I will reply eventually.**

The complete result/error text is especially useful because it may identify the exact asset, bone, curve, track, or output operation that could not be completed.

# Ako Animation Modifier

Ako Animation Modifier is a focused set of animation-editing tools for Unreal Engine. It helps artists and animators correct, clean, transform, combine, and prepare animation assets directly inside the Animation Editor.

## Supported Unreal Engine Versions

- **Ako Animation Modifier 1.19.0 — Unreal Engine 5.2–5.4**
- **Ako Animation Modifier 1.19.0 — Unreal Engine 5.5–5.8**

The documentation is written for end users. It does not require C++ or Unreal Engine plugin-development knowledge.

## Start Here

If this is your first time using the plugin, begin with [Getting Started](getting-started/index.md), then choose the tool that matches the task you need to perform.

## What You Can Do

- Correct Root and Pelvis motion setup
- Correct Root Motion direction
- Remove unnecessary bone tracks
- Snap animation to the floor
- Align IK bones to their targets
- Mirror, reverse, and loop animation
- Combine two Animation Sequences
- Blend one animation branch into another
- Convert an Animation Composite into an Animation Sequence

# Choosing the Right Tool



| Goal                                                       | Tool                                              |
| ---------------------------------------------------------- | ------------------------------------------------- |
| Correct Root initialization or transfer Root/Pelvis motion | Fix Root                                          |
| Rotate the Root Motion travel direction                    | Fix Animation Orientation                         |
| Remove specific bone tracks                                | Remove Bone Track Manually                        |
| Detect driven bone tracks automatically                    | Remove Bone Track Auto                            |
| Place the animation on the floor                           | Snap Animation To Floor                           |
| Make IK bones follow targets                               | Snap IK Bones                                     |
| Bake mirrored animation                                    | Mirror Animation                                  |
| Reverse animation data                                     | Reverse Animation                                 |
| Add an end-to-start loop transition                        | Make Animation Loop                               |
| Append or blend two animations into a new sequence         | Combine Animation Sequences                       |
| Bake one bone branch from another animation                | Layered Blend Per Bone                            |
| Bake an Animation Composite into a new Animation Sequence  | Convert Animation Composite to Animation Sequence |
| Remove forward movement from the character                 | Make Animation In Place                           |
| Transfer Pelvis motion to the Root                         | Create Root Motion                                |

# Getting Started

Ako Animation Modifier is designed for artists and animators who need to perform common animation corrections and preparation tasks to <mark style="color:$success;">**save hour**</mark> of editing without leaving Unreal Engine's Animation Editor.

<div><figure><img src="../.gitbook/assets/Cap 2026-09-27 21-25-12.jpg" alt=""><figcaption></figcaption></figure> <figure><img src="../.gitbook/assets/Cap 2026-09-27 21-25-31.jpg" alt=""><figcaption></figcaption></figure></div>

## What You Need

Before using a tool, make sure the required asset is open:

* Most tools require open an <mark style="color:$primary;">**Animation Sequence**</mark>.
* **Convert Animation Composite to Animation Sequence** requires open an <mark style="color:green;">**Animation Composite**</mark><mark style="color:green;">.</mark>

<mark style="color:purple;">The tool window shows the active animation and Skeleton so you can verify that you are working on the intended asset.</mark>

<figure><img src="../.gitbook/assets/Cap 2026-09-27 21-24-50.jpg" alt=""><figcaption></figcaption></figure>

## Main Tool Categories

### Fix Tools

Use these for correction and cleanup tasks such as Root setup, Root Motion orientation, and bone-track removal.

<figure><img src="../.gitbook/assets/Cap 2026-09-27 21-19-19.jpg" alt=""><figcaption></figcaption></figure>

### Motion Tools

Use these for floor alignment and IK-related work.

<figure><img src="../.gitbook/assets/Cap 2026-09-27 21-19-29.jpg" alt=""><figcaption></figcaption></figure>

### Timing Tools

Use these for mirroring, reversing, and creating loop transitions.

<figure><img src="../.gitbook/assets/Cap 2026-09-27 21-19-46.jpg" alt=""><figcaption></figcaption></figure>

### Blend Tools

Use these when combining animations or baking a selected bone branch from another animation.

<figure><img src="../.gitbook/assets/Cap 2026-09-27 21-19-40.jpg" alt=""><figcaption></figcaption></figure>

### Conversion

Use this when you need to bake an Animation Composite into a new Animation Sequence.

## <mark style="color:$warning;">FOR A Good First Test</mark>

For your first test, use a <mark style="color:$warning;">Duplicated</mark> or test animation. This gives you a safe way to learn the workflow and inspect the result before applying the same operation to final content.

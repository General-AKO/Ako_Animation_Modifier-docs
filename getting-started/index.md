# Getting Started

Ako Animation Modifier is designed for artists and animators who need to perform common animation corrections and preparation tasks without leaving Unreal Engine's Animation Editor.

## What You Need

Before using a tool, make sure the required asset is open:

- Most tools require an **Animation Sequence**.
- **Convert Animation Composite to Animation Sequence** requires an **Animation Composite**.

The tool window shows the active animation and Skeleton so you can verify that you are working on the intended asset.

## Main Tool Categories

### Fix Tools

Use these for correction and cleanup tasks such as Root setup, Root Motion orientation, and bone-track removal.

### Motion Tools

Use these for floor alignment and IK-related work.

### Timing Tools

Use these for mirroring, reversing, and creating loop transitions.

### Blend Tools

Use these when combining animations or baking a selected bone branch from another animation.

### Conversion

Use this when you need to bake an Animation Composite into a new Animation Sequence.

## A Good First Test

For your first test, use a duplicated or test animation rather than a production asset. This gives you a safe way to learn the workflow and inspect the result before applying the same operation to final content.

# Workflow Troubleshooting

Before reporting a problem, check the following:

1. The correct Animation Sequence or Animation Composite is open.
2. The Skeleton is valid.
3. The required bones still exist on the current Skeleton.
4. Source animations use compatible Skeletons where required.
5. Required options, axes, ranges, and sampling rates are selected.
6. Output paths do not point to an existing conflicting asset.
7. Mirror workflows use a compatible Mirror Data Table when required.
8. The tool's result or analysis area has been checked.

When a tool provides an analysis step, do not skip directly to the final action. The analysis is often where the plugin explains what it found and what still needs to be resolved.

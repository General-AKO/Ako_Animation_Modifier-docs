# Troubleshooting

When an operation does not complete, start with the exact result or error message shown by the plugin.

Most problems are caused by one of these conditions:

- the wrong asset type is open
- the Skeleton or selected bone is invalid
- a required option or axis is not selected
- a frame range is invalid
- source animations use incompatible Skeletons
- the output path or asset name is invalid
- required animation data is unavailable

See [Errors and Messages](errors-and-messages.md) for individual messages and [FAQ](faq.md) for common workflow questions.

# Quick Reference

| Tool | Main Purpose | Source Modified? |
|---|---|---|
| Fix Root Zero Frame | Correct Root initialization and transfer Root/Pelvis motion | Yes |
| Fix Animation Orientation | Rotate Root Motion translation direction | Yes |
| Remove Bone Track Manually | Remove selected bone tracks | Yes |
| Remove Bone Track Auto | Detect and remove driven bone tracks | Yes |
| Snap Animation To Floor | Place the lowest mesh point on the floor | Yes |
| Snap IK Bones | Make IK tracks follow target bones | Yes |
| Mirror Animation | Bake mirrored animation data | Yes |
| Reverse Animation | Reverse selected animation data | Yes |
| Make Animation Loop | Add an end-to-start loop transition | Yes |
| Combine Animation Sequences | Append or blend two animations into a new sequence | No — creates new output |
| Layered Blend Per Bone | Bake a bone branch from another animation into a new sequence | No — creates new output |
| Convert Animation Composite to Animation Sequence | Bake a Composite into a new sequence | No — creates new output |
| Make Animation In Place | Prepare an animation for In Place playback | Yes |
| Create Root Motion | Transfer Pelvis motion to the Root | Yes |

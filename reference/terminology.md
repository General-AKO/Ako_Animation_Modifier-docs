# Terminology

### Animation Sequence

A standard Unreal animation asset containing sampled animation data such as bone transforms, curves, notifies, and sync markers.

### Animation Composite

An Unreal animation asset that combines animation segments and can be baked into a new Animation Sequence.

### Bone Track

Animation data associated with a Skeleton bone.

### Root Motion

Movement represented by the Root bone so the character's travel can be handled separately from local body motion.

### In Place

An animation where the character does not travel through the world, allowing movement to be handled separately.

### IK Bone

A bone used as an inverse-kinematics control point, normally paired with a target bone.

### Mirror Data Table

An Unreal asset that defines how bones and related animation elements correspond to mirrored counterparts.

### LOD

Level of Detail. For mesh sampling, lower LOD numbers normally represent more detailed mesh data.

### Sampling Rate

The number of samples evaluated per second when animation data is rebuilt by a bake or combination operation.
